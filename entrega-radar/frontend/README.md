Execute o backend e abra http://localhost:3000. A interface usa Fetch na mesma origem da API e mantém o token em memória.

Após entrar como empresa contratante, use **Pedidos de materiais** para cadastrar, consultar, editar e excluir pedidos. A lista mostra a etapa de cada pedido e destaca prazos vencidos. A API verifica o perfil, a empresa e a etapa antes de permitir alterações.
