# Middlewares

Pasta reservada para os middlewares das próximas etapas:

- Autenticação: verificar o JWT do usuário.
- Autorização: conferir o perfil e o vínculo com a empresa ou transportadora.
- Validações compartilhadas, quando necessárias.

Nenhuma dessas verificações está implementada na Entrega 1. A rota inicial é pública e não contém dados de empresas ou de pedidos.
