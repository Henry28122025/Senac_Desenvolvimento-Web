# Banco de dados

Pasta reservada para a conexão com o MySQL, prevista para a Entrega 2.

O arquivo de conexão utilizará variáveis de ambiente. Dados privados não deverão ser escritos diretamente no código nem enviados ao GitHub. Os scripts de criação das tabelas ficarão na pasta `sql`, na raiz deste projeto.

Nesta etapa não há conexão com banco nem credenciais de acesso.
