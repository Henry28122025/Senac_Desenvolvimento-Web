# Controllers

O controller inicial retorna a identificação do projeto.

Os arquivos iniciais dos demais controllers já estão criados por módulo, seguindo a organização do `sistema_RPG`. Eles ainda não implementam funcionalidades. Nas próximas etapas serão responsáveis por tratar as requisições, validar dados, consultar o banco e aplicar as regras dos recursos.

Módulos reservados: autenticação, usuários, administração, empresas, transportadoras, pedidos, solicitações, entregas, previsões e alertas. O cálculo de previsão poderá ser separado em outro módulo quando for desenvolvido, para não ficar misturado à configuração do servidor.
